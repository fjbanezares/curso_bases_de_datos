El estado ni siquiera tiene que guardarse en nuestro disco duro local. Tal como ocurre con GitHub, tenemos un servicio exterior que nos sirve los datos mediante una API de sincronización.

🔌

Todo son APIs

Git es una API. Cada llamada del runtime de Python o Java es una API: un contrato estandarizado con el que el compilador o intérprete interactúa con nosotros de forma predecible.

Object Storage (S3 / GCS)

No todo son filas. En AWS S3 o Google Cloud Storage guardamos blobs inmutables: PDFs de extractos, fotos de DNIs y backups masivos con durabilidad garantizada del 99.999999999%.

Módulo II • Modelado Relacional y Negocio

El Arte del Modelo Entidad-Relación y las 3 Formas Normales

Modelar datos tiene cierta forma de arte. Si ponemos todo a lo bruto en un solo punto, puede parecer cómodo para el frontend porque todo llega en una sola fila. Pero destruye la consistencia y multiplica exponencialmente el espacio en disco.

1NF • Atomicidad

Cero Grupos Repetitivos

Cada celda contiene un único valor escalar indivisible. Quedan prohibidas las listas separadas por comas ('Gran Vía 45, Playa 12') y las columnas repetitivas (casa_1, casa_2).

2NF • Dependencia Total

Toda la Clave Primaria

Cumple 1NF y cada columna que no es clave depende por completo de toda la clave primaria. El concepto de la compra o el importe dependen del ID de la transacción, no del nombre del cliente.

3NF • Cero Transitividad

Sin Atributos Transitivos

Ningún atributo depende de otro que no sea la clave primaria. La ciudad depende del código postal, no directamente de la persona. Extraerlo crea una única fuente de verdad inmutable.

Módulo IV • Ecosistema NoSQL y Big Data

El Salto a la Escala: ETLs, HBase, Cassandra, Mongo y Neo4J

Cuando un front-end de banca móvil exige responder a 10 millones de usuarios en menos de 5 milisegundos, no podemos ejecutar JOINs cruzados en tiempo real. Usamos procesos Batch/ETL y bases de datos especializadas.

HBase: El Secreto de la RowKey Invertida

En una aplicación bancaria móvil, el cliente siempre quiere ver sus últimos movimientos de hoy, no los de hace 5 años. Guardamos la clave física restando el timestamp al valor máximo de un entero de 64 bits (Long.MAX_VALUE - timestamp).

Generador de RowKey Dinámica

RowKey Generada en HBase:
CUST#001_9223370311844775807
Apache Phoenix / HBase Shell
-- Lectura instantánea en 1 milisegundo:
SCAN 'bank_statements', {
  STARTROW => 'CUST#001_',
  STOPROW  => 'CUST#001_~',
  LIMIT    => 10
}
-- Phoenix añade sintaxis SQL sobre HBase:
SELECT * FROM bank_statements 
WHERE rowkey LIKE 'CUST#001_%' 
LIMIT 10;

Cassandra y CQL: La Base de Datos sin JOINs

Cassandra está diseñada para escribir 1 millón de transacciones por segundo en cientos de nodos peer-to-peer. Cada tabla se modela pensando en una sola pantalla del usuario.

Cassandra Query Language (CQL)
-- Partición por customer_id; Ordenación física en disco por fecha DESC:
CREATE TABLE customer_tx_by_date (
    customer_id int,
    transaction_time timestamp,
    transaction_id uuid,
    customer_name text static, -- Columna estática única para todas las filas del cliente
    concept text,
    amount decimal,
    PRIMARY KEY ((customer_id), transaction_time, transaction_id)
) WITH CLUSTERING ORDER BY (transaction_time DESC);

-- ¡No hace falta ordenar en memoria! La lectura es un puntero continuo a disco en 2ms:
SELECT customer_name, transaction_time, concept, amount 
FROM customer_tx_by_date 
WHERE customer_id = 1 
LIMIT 10;

Matriz Comparativa de Ingeniería

El Mapa de Decisión del Arquitecto Políglota

Ninguna tecnología es una bala de plata. Compara las fortalezas y las debilidades de cada motor según el caso de uso real de tu organización.

Base de Datos Paradigma Punto Fuerte Absoluto Punto Débil Crítico Caso de Uso Óptimo
PostgreSQL / Oracle Relacional (3NF) Garantía transaccional ACID estricta y consultas ad-hoc con JOIN. Escrituras masivas a escala global (>500k writes/seg sin sharding). Libro mayor bancario, balances contables, compras en comercio.
MongoDB Documental BSON Flexibilidad de esquema y lectura de documentos anidados sin JOIN. Relaciones complejas cruzadas que exigen múltiples $lookup. Catálogos de productos, perfiles de usuario, carritos web.
Apache Cassandra Wide-Column P2P Escritura brutalmente rápida y tolerancia a fallos 100% sin máster. Imposibilidad total de hacer JOINs o consultas no modeladas en la clave. Sensores IoT, telemetría, timelines masivos de redes sociales.
Apache HBase Columnar sobre HDFS Escaneo por rangos de petabytes en 1ms gracias a la RowKey. Falta de índices secundarios y complejidad operativa de Hadoop. Historial de extractos bancarios de 10 años servidos a móviles.
Neo4J Grafo de Propiedades Recorridos ultrarrápidos de relaciones multinivel profundas con Cypher. Almacenamiento tabular de transacciones o reporting analítico pesado. Detección de fraude, blanqueo de capitales, motores de recomendación.
