Laboratorio de Datos: Alternativas PostgreSQL

Como complemento a nuestro trabajo con arquitecturas NoSQL (MongoDB) y despliegues en AWS, aquí tenéis las mejores plataformas Cloud gratuitas para instanciar bases de datos relacionales y conectar vuestros scripts de Python o proyectos desde VS Code.

Neon.tech Recomendado

  • Almacenamiento: 0.5 GB
  • Tarifa: Gratis permanente
  • Tarjeta de crédito: No requerida

El estándar moderno actual para PostgreSQL *Serverless*. Su principal ventaja didáctica es que permite crear ramas de bases de datos (branching), aplicando exactamente la misma lógica que estamos estudiando con Git: podéis hacer una rama para pruebas, romper los datos y volver a la principal sin consecuencias.

Supabase Visual

  • Almacenamiento: 500 MB
  • Tarifa: 2 proyectos gratis
  • Tarjeta de crédito: No requerida

Una alternativa muy amigable que funciona sobre un PostgreSQL estándar. Destaca por su excelente interfaz web, que os permitirá visualizar las tablas y escribir sentencias SQL directamente desde el navegador, ideal para repasar sintaxis antes de conectar la base de datos a vuestro código.

Aiven.io Capacidad

  • Almacenamiento: 5 GB
  • Tarifa: 1 nodo gratuito
  • Tarjeta de crédito: No requerida

Un servicio de infraestructura en la nube más tradicional. Es la opción más generosa en espacio para vuestros conjuntos de datos (*datasets*) de mayor volumen. Os proporcionará una cadena de conexión estándar (URI) perfecta para integrar con librerías de conexión estándar.

* Nota: Excelente para simulaciones de Machine Learning básico donde necesitemos almacenar históricos de datos más pesados.
