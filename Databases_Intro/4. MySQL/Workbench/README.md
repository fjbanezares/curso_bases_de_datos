# 🛠️ MySQL Workbench: Guía Visual, Arquitectura y Constraints

En esta carpeta encontrarás los recursos didácticos visuales y prácticos para dominar **MySQL Workbench**, la arquitectura de MySQL y las restricciones de integridad relacional:

- 📖 **[Guía Visual de Workbench y Constraints (`Guia_Visual_Workbench_y_Constraints.md`)](./Guia_Visual_Workbench_y_Constraints.md)**: Manual exhaustivo con storytelling didáctico de las 12 láminas, trucos para obtener el diagrama EER por ingeniería inversa, explicación profunda de constraints (`ON DELETE RESTRICT`, `CASCADE`, `SET NULL`, `CHECK`, etc.), usuarios, copias de seguridad y escalado.
- 💾 **[Script SQL de Práctica (`academia_practica.sql`)](./academia_practica.sql)**: Código DDL/DML ejecutable para crear la base de datos `academia`, reproducir consultas y ensayar uno a uno los errores del guardián de integridad.
- 📑 **[Guía Visual en PDF (`MySQL_Workbench_guia_visual.pdf`)](./MySQL_Workbench_guia_visual.pdf)**: Las 12 láminas en formato documento imprimible.
- 🖼️ **Infografías en PNG**: Las 12 láminas individuales de alta resolución que ilustran cada capítulo.
